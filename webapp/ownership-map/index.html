    Format help
    • Standard rows: owner, owned, ownership, % or person, company, role.
    • Sentences in Indonesian or English work too, such as Andi owns 40% of PT Sejahtera.
    • Add recent or previous, and a date like 2022-06, as extra columns: PT A,PT B,ownership,40,2022-06,previous.
    • The same stake or role seen again at a later date is one relationship with several dates. Anything a company’s latest extract no longer lists counts as previous.
    • AHU tables list the company first: company, party, role or Shareholder, %. Auto-detect usually spots them; you can also pick the format below.
    • Wrap a name containing a comma in quotes: "PT Foo, Bar".

      How to connect
      • Open github.com/settings/personal-access-tokens/new.
      • Repository access: Only select repositories → rumahkerumah.
      • Repository permissions: Contents → Read and write. Nothing else.
      • Generate the token, copy it, choose Connect GitHub here and paste it.
      • The token stays in this browser only. Connect once per browser or device.
